Privacy and control

Built around review.

What Inbox Tend reads, what it keeps, and what it never does.

Reads

After you connect Gmail with read-only consent, the app downloads your recent inbox messages: headers, text and HTML bodies, labels and attachments up to a size limit. Gmail is contacted only to connect and when you press Refresh inbox.

Keeps

Everything it downloads is saved in a SQLite database on the server that runs Inbox Tend, together with the tasks you confirm. Only your Gmail refresh token is encrypted, so protect that server. Disconnecting Gmail deletes the saved messages and attachments.

Never does

No sending, deleting or modifying mail in Gmail. No AI model sees your messages. Message bodies show as plain text only and attachments are never opened or run, only downloaded. Agent assignments only record a pending approval and run nothing.

Your controls

Disconnect or delete any time.

Disconnect Gmail from the Inbox page to remove the stored token. Deleting a task permanently removes it and its activity history. Public pages contain no inbox or task data.
