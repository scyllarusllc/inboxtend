Mail sync

Changes apply to the next sync. Already stored mail is kept. The Gmail searches themselves (INBOX_TEND_SYNC_QUERY, INBOX_TEND_SYNC_SENT_QUERY) are set in .env.

AI assistant (Codex CLI)

Uses the codex command on this server to suggest tasks (with quoted evidence from the message) and to draft replies. Off by default. When on, pressing an AI button sends that one message’s sender, date, subject and text, and optionally small text attachments, to OpenAI through this server’s Codex login. Nothing is sent automatically, no reply is ever sent, and every result is only a suggestion you review.
